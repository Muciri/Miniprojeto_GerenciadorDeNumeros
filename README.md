# Gerenciador de Números em Go

Atividade de nivelamento em Go da disciplina de **Programação Distribuída**. Com objetivo de praticar conceitos básicos da linguagem, como variáveis, condicionais, loops, funções, slices, múltiplos retornos e tratamento de erros.

## Funcionalidades

* Adicionar números à lista
* Listar números armazenados
* Remover número por índice
* Calcular mínimo, máximo e média
* Realizar divisão de doius numeros
* Limpar a lista
* Listar apenas números pares
* Ordenar a lista em ordem crescente
* Ordenar a lista em ordem decrescente
* exportar lista para arquivo texto

## Como executar

```bash
go run main.go
```
